# Sotto v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local-only, macOS noise-cancelling virtual microphone ("Sotto Microphone") that any call app can select, cleaning the user's mic with DeepFilterNet3.

**Architecture:** A HAL audio-server plug-in (C++/libASPL) presents a visible "Sotto Microphone" input and a hidden "Sotto Bridge" output linked by a lock-free ring. A Rust static library wraps DeepFilterNet3 behind a C ABI. A Swift menu-bar app captures the real mic on a real-time thread, runs the denoiser, and writes the result into the bridge; the driver loops it to the visible mic.

**Tech Stack:** C++17 + libASPL v3.1.2 + CMake (driver), Rust + the `deep_filter` crate v0.5.6 with the `tract` backend (denoiser), Swift 6 / SwiftUI `MenuBarExtra` + Core Audio (app), Python/uv (existing benchmark harness).

**Spec:** [docs/superpowers/specs/2026-10-12-sotto-v0.1-design.md](../specs/2026-10-12-sotto-v0.1-design.md)

## Global Constraints

- **License:** MIT for all Sotto code. Do NOT copy GPL code from BlackHole or Background Music; use libASPL (MIT) for the driver. Keep upstream attribution for libASPL and DeepFilterNet.
- **Clean-room:** no Krisp code, models, decompiled pseudocode, or `.kef` material enters the repo. `docs/krisp-architecture.md` is behavioural notes only.
- **No network:** the app has no network entitlement, no accounts, no telemetry.
- **Platform:** macOS 14+ on Apple Silicon (Intel best-effort). Swift tools version 6.0; every SwiftPM package sets `platforms: [.macOS(.v14)]` (required — the default floor breaks Swift Testing macros under Command Line Tools).
- **Audio format:** 48 kHz, mono, float32 internally and on both driver devices. 48 kHz only in v0.1.
- **Real-time rule:** no locks, heap allocation, logging, or Swift/CF/ObjC calls on any Core Audio IO thread or the DSP thread's steady-state loop.
- **Identifiers (verbatim):** app bundle `io.github.sotto-audio.Sotto`; driver bundle `io.github.sotto-audio.SottoAudio`; device UIDs `SottoMicrophone` and `SottoBridge`; custom property selectors `'sRun'`, `'sBrg'`, `'sHid'` (FourCharCodes); driver install path `/Library/Audio/Plug-Ins/HAL/SottoAudio.driver`.
- **DeepFilterNet strength mapping (verbatim):** `atten_lim_db = strength * 0.4` for strength in 0..99; strength 100 → no attenuation limit (full reduction). Hop size is 480 samples.
- **Latency/CPU targets:** end-to-end added latency ≤ 60 ms; DSP thread < 10% of one core on an Apple Silicon MacBook Air.

## Review Focus

- **Physical mic at a non-48kHz rate (e.g. 44.1 kHz, or 16 kHz Bluetooth):** capture must resample to 48 kHz before the denoiser; wrong-rate audio would pitch-shift or glitch. Pinned in Task 9.
- **Selected mic disappears mid-call (AirPods/USB unplug):** engine must fall back to another device and rebuild without crashing or emitting indefinite silence. Pinned in Task 13.
- **Denoiser returns an error or the model fails to load:** must fail open (pass input through), never silence or crash the call. Pinned in Tasks 5 and 11.
- **Unauthorized process opens Sotto Bridge:** must receive silence / no bridge data; only the signed Sotto app (by Team ID, or exact bundle ID for unsigned local builds) is served. Pinned in Task 7.
- **DSP slower than real time (overload):** must crossfade to bypass and keep the call alive, not accumulate latency or drop out. Pinned in Task 12.

## Task 3: Denoiser — load DeepFilterNet3 and report hop/latency

**Files:**

**Interfaces:**

- Produces: the C ABI from Task 2.

- [ ] **Step 1: Implement the struct and lifecycle in `denoiser/src/lib.rs`**

```rust
use deep_filter::tract::{DfParams, DfTract, RuntimeParams};
use ndarray::ArrayView2;
use std::panic::{catch_unwind, AssertUnwindSafe};

pub struct SottoDenoiser {
    model: DfTract,
    scratch_out: Vec<f32>,
}

#[no_mangle]
pub extern "C" fn sotto_denoiser_new() -> *mut SottoDenoiser {
    let r = catch_unwind(|| {
        let params = DfParams::default();
        let rp = RuntimeParams::default_with_ch(1);
        let model = DfTract::new(params, &rp).ok()?;
        let hop = model.hop_size;
        Some(Box::new(SottoDenoiser { model, scratch_out: vec![0.0; hop] }))
    });
    match r {
        Ok(Some(b)) => Box::into_raw(b),
        _ => std::ptr::null_mut(),
    }
}

#[no_mangle]
pub extern "C" fn sotto_denoiser_hop_size(d: *const SottoDenoiser) -> u32 {
    if d.is_null() { return 0; }
    unsafe { (*d).model.hop_size as u32 }
}

#[no_mangle]
pub extern "C" fn sotto_denoiser_latency_samples(d: *const SottoDenoiser) -> u32 {
    if d.is_null() { return 0; }
    unsafe { ((*d).model.lookahead * (*d).model.hop_size) as u32 }
}

#[no_mangle]
pub extern "C" fn sotto_denoiser_free(d: *mut SottoDenoiser) {
    if !d.is_null() { unsafe { drop(Box::from_raw(d)); } }
}
```

```rust
#[no_mangle]
pub extern "C" fn sotto_denoiser_process(d: *mut SottoDenoiser, input: *const f32, output: *mut f32) -> i32 {
    if d.is_null() || input.is_null() || output.is_null() { return -2; }
    let r = catch_unwind(AssertUnwindSafe(|| {
        let this = unsafe { &mut *d };
        let hop = this.model.hop_size;
        let inp = unsafe { std::slice::from_raw_parts(input, hop) };
        let noisy = ArrayView2::from_shape((1, hop), inp).unwrap();
        let mut enh = ndarray::ArrayViewMut2::from_shape((1, hop), &mut this.scratch_out).unwrap();
        this.model.process(noisy, enh.view_mut()).map(|_| ())
    }));
    match r {
        Ok(Ok(())) => {
            let this = unsafe { &mut *d };
            unsafe { std::ptr::copy_nonoverlapping(this.scratch_out.as_ptr(), output, this.model.hop_size); }
            0
        }
        _ => -1,
    }
}
```

## Notes for the executor

- **First `cargo test` is slow:** tract + DeepFilterNet compile can take several minutes and download the embedded model crate. This is expected.
- **Swift Testing under Command Line Tools** needs the `-F`/`-Xlinker -rpath` flags pointing at `…/CommandLineTools/Library/Developer/Frameworks` and `…/usr/lib`, and every `Package.swift` must set `platforms: [.macOS(.v14)]`. If full Xcode is installed, neither is needed.
- **Driver iteration:** after each `make install`, `coreaudiod` restarts and all audio drops for ~1–2 s. Don't run driver installs mid-call.
- **Unsigned local builds** work: `SOTTO_TEAM_ID` stays empty and the bridge auth falls back to the exact bundle ID `io.github.sotto-audio.Sotto`. Signing is only needed for distributable `.pkg`s.
- **CMake/Python** are required for the driver build (libASPL runs Python codegen at configure time). `brew install cmake` and system Python 3 suffice.
